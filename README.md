# Lina Samuelsson · Portfolio

**Live:** https://linaslala.github.io

> Jag förstår siffrorna, kunden och koden, och gillar när de pratar med varandra.

Min personliga portfolio som blivande systemutvecklare inom .NET (YH Akademin, LIA 2027). Sidan visar vem jag är, vad jag kan och vart jag är på väg, i en lugn, minimalistisk stil inspirerad av japansk akvarell.

## Innehåll

- **Om mig** – före, nu och sedan, och vad andra säger
- **CV** – tidslinje, teknik, verktyg och nedladdningsbart CV (PDF)
- **Projekt** – kommande projekt per kurs, plus AI och automation
- **Det jag lärt mig** – kurser på YH Akademin och lärdomar om AI
- **Mina tankar om AI** – om AI-generalister, AGI och vad som blir mänskligt viktigt
- **Min bokhylla** – favoritböcker (hämtas senare från mitt eget API)
- **Kontakt** – formulär via Web3Forms

## Funktioner

- Svenska och engelska med språkväxlare
- Ljust och mörkt läge – på natten blir solen en måne och datorn lyser som en lykta
- Modaler i stället för lång scroll, med fokusfångst och stängning med Esc
- Mobil först, hela illustrationen syns på alla skärmar
- Illustrationen och tallgrenarna på knapparna är målade i kod (SVG), och varje gren är unik
- Tar hänsyn till inställningen för minskad rörelse

## Teknik

Ren HTML, CSS och vanilla JavaScript. Inget ramverk och inget byggsteg. Typsnitt från Google Fonts (Yuji Boku och Zen Kaku Gothic New). Publicerad med GitHub Pages.

```
index.html          sidan och illustrationen
css/style.css       färger, layout och ljust/mörkt läge
js/main.js          modaler, språk, tema, tallgrenar och kontaktformulär
content/texts.js    all text på svenska och engelska
assets/             porträtt och CV
```

Sidan fungerar även direkt från disk: öppna `index.html` i webbläsaren.

## Byggd med AI

Sidan är byggd till 100 % med AI, med Claude Code som verktyg. Jag bestämde, AI skrev. Arbetet styrdes av en regelfil ([CLAUDE.md](CLAUDE.md)) och granskades punkt för punkt. Hela prompthistoriken finns i [docs/prompt-library.md](docs/prompt-library.md), och arbetsgången beskrivs under *Hur jag byggt min sida* i sidfoten.
